# Publishing

The playbook is republished each quarter. The publishing desk owns the release process and the
archive of superseded editions.

## Release procedure

1. Build the documentation bundle.
2. Review the staging preview.
3. Archive the superseded edition.

Only pages that have been cleared for publication are included in a release. Pages that are
still being drafted stay in the working copy until the next edition.
